# Rusticando

Sitio web de **Rusticando**, muebles artesanales en madera maciza hechos a mano en San José, Uruguay.

- Catálogo de piezas con consulta directa por WhatsApp
- Maderas: ciprés, pino marítimo y cedro azul
- Envíos a todo Uruguay

Contacto: WhatsApp 098 923 479 · Instagram [@rusticando.uy](https://www.instagram.com/rusticando.uy/)

Sitio estático (HTML + CSS), publicado con GitHub Pages.

## Panel de administración

El cliente carga, edita y oculta piezas desde `/admin/` (acceso: el © del pie de página).
El catálogo se guarda en Supabase. Instrucciones para conectarlo: [`supabase/LEEME.md`](supabase/LEEME.md).
